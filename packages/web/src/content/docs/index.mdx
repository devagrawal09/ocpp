[**OC++**](/) is an open source AI coding agent. Running `ocpp` opens the OC++ web app in your browser, and the [CLI](/docs/cli) lets you use it from scripts and automation.

![OC++ web app](../../assets/web/web-homepage-new-session.png)

Let's get started.

---

#### Prerequisites

To use OC++, you'll need API keys for the LLM providers you want to use.

## Install

The easiest way to install OC++ 1 is through the install script. These installation methods provide the `ocpp`
binary and do not replace an `ocpp` installation.

```bash
curl -fsSL https://ocpp.ai/install | bash
```

You can also install it with the following commands:

## Configure

With OC++ you can use any LLM provider by configuring their API keys.

If you are new to using LLM providers, we recommend using [OpenCode Zen](/docs/zen).
It's a curated list of models that have been tested and verified by the OC++
team.

1. In the web app, open the command palette with **Cmd+K** (**Ctrl+K** on Windows and Linux), run **Connect provider**, select ocpp, and head to [opencode.ai/auth](https://opencode.ai/auth).

2. Sign in, add your billing details, and copy your API key.

3. Paste your API key.

Alternatively, you can select one of the other providers. [Learn more](/docs/providers#directory).

## Initialize

Now that you've configured a provider, run OC++. It starts the OC++ server if
it isn't already running and opens the web app in your browser.

```bash
ocpp
```

From the home page, open the project that you want to work on.

Next, initialize OC++ for the project by running the following command.

```bash frame="none"
/init
```

This will get OC++ to analyze your project and create an `AGENTS.md` file in
the project root.

:::tip
You should commit your project's `AGENTS.md` file to Git.
:::

This helps OC++ understand the project structure and the coding patterns
used.

## Usage

You are now ready to use OC++ to work on your project. Feel free to ask it
anything!

If you are new to using an AI coding agent, here are some examples that might
help.

---

### Ask questions

You can ask OC++ to explain the codebase to you.

:::tip
Use the `@` key to fuzzy search for files in the project.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
How is authentication handled in @packages/functions/src/api/index.ts
```

This is helpful if there's a part of the codebase that you didn't work on.

---

### Add features

You can ask OC++ to add new features to your project. Though we first recommend asking it to create a plan.

1. **Create a plan**

   OC++ has a _Plan mode_ that disables its ability to make changes and
   instead suggest _how_ it'll implement the feature.

   Switch to it with the agent picker in the prompt, or run the `/agent` command.

   ```bash frame="none" title="Switch to Plan mode"
   /agent
   ```

   Now let's describe what we want it to do.

   ```txt frame="none"
   When a user deletes a note, we'd like to flag it as deleted in the database.
   Then create a screen that shows all the recently deleted notes.
   From this screen, the user can undelete a note or permanently delete it.
   ```

   You want to give OC++ enough details to understand what you want. It helps
   to talk to it like you are talking to a junior developer on your team.

   :::tip
   Give OC++ plenty of context and examples to help it understand what you
   want.
   :::

2. **Iterate on the plan**

   Once it gives you a plan, you can give it feedback or add more details.

   ```txt frame="none"
   We'd like to design this new screen using a design I've used before.
   [Image #1] Take a look at this image and use it as a reference.
   ```

   :::tip
   Drag and drop images into the prompt to add them.
   :::

   OC++ can scan any images you give it and add them to the prompt. You can
   do this by dragging and dropping an image into the prompt.

3. **Build the feature**

   Once you feel comfortable with the plan, switch back to _Build mode_ the
   same way, and ask it to make the changes.

   ```bash frame="none"
   Sounds good! Go ahead and make the changes.
   ```

---

### Make changes

For more straightforward changes, you can ask OC++ to directly build it
without having to review the plan first.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
We need to add authentication to the /settings route. Take a look at how this is
handled in the /notes route in @packages/functions/src/notes.ts and implement
the same logic in @packages/functions/src/settings.ts
```

You want to make sure you provide a good amount of detail so OC++ makes the right
changes.

---

### Undo changes

Let's say you ask OC++ to make some changes.

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

But you realize that it is not what you wanted. You **can undo** the changes
using the `/undo` command.

```bash frame="none"
/undo
```

OC++ will now revert the changes you made and show your original message
again.

```txt frame="none" "@packages/functions/src/api/index.ts"
Can you refactor the function in @packages/functions/src/api/index.ts?
```

From here you can tweak the prompt and ask OC++ to try again.

:::tip
You can run `/undo` multiple times to undo multiple changes.
:::

Or you **can redo** the changes using the `/redo` command.

```bash frame="none"
/redo
```

## Share

The conversations that you have with OC++ can be [shared with your
team](/docs/share).

```bash frame="none"
/share
```

This will create a link to the current conversation and copy it to your clipboard.

:::note
Conversations are not shared by default.
:::
