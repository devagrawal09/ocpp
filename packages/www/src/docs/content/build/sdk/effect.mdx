title: "Effect"
---

`@ocpp/sdk/effect` is the Effect-native embedded SDK. Operations return typed Effects and Streams, and closing
the owning Scope releases the router, Location services, fibers, and plugin registrations.

```sh
bun add @ocpp/sdk@dev effect
```

## Create a host

Create the host inside `Effect.scoped`, then use its generated API groups or the `sessions` alias.

```ts
import { AbsolutePath, Location, OC++ } from "@ocpp/sdk/effect"
import { Effect } from "effect"

const program = Effect.scoped(
  Effect.gen(function* () {
    const ocpp = yield* OC++.create()
    const session = yield* ocpp.sessions.create({
      location: Location.Ref.make({ directory: AbsolutePath.make("/workspace") }),
    })
    yield* ocpp.sessions.prompt({
      sessionID: session.id,
      text: "Review the current changes",
    })
    return session
  }),
)

const session = await Effect.runPromise(program)
```

The embedded host uses the same schema values, declared errors, request options, and Streams as
`@ocpp/client/effect`.

```ts
const health = yield * ocpp.health.get()
const sessions = yield * ocpp.sessions.list()
```

## Stream events

Streaming endpoints return Effect `Stream` values. Fork consumers in the host Scope when they should run in the
background.

```ts
import { Effect, Stream } from "effect"

yield *
  ocpp.events.subscribe().pipe(
    Stream.runForEach((event) => Effect.logInfo("OC++ event", { type: event.type })),
    Effect.forkScoped,
  )
```

## Customize

Customize your OC++ instance by registering Effect plugins. Use the embedded
host to customize agents, models, tools, and other behavior:

```ts
import { Plugin } from "@ocpp/plugin/effect"
import { Effect } from "effect"

const plugin = Plugin.define({
  id: "customize-agent",
  effect: (ctx) =>
    Effect.gen(function* () {
      const agent = ctx.agent
      yield* agent.transform((agents) => {
        agents.update("build", (agent) => {
          agent.description = "Builds features and fixes bugs for our team"
        })
      })
    }),
})

yield * ocpp.plugin(plugin)
```

See the [full Effect plugins documentation](/build/plugins/effect) for plugin
hooks, transforms, tools, and the complete plugin context.

## Layer

Use `OC++.layer()` when the embedded host should be an application service.

```ts
import { OC++ } from "@ocpp/sdk/effect"
import { Effect } from "effect"

const program = Effect.gen(function* () {
  const ocpp = yield* OC++.Service
  return yield* ocpp.health.get()
})

const health = await Effect.runPromise(program.pipe(Effect.provide(OC++.layer())))
```
