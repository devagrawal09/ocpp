`@ocpp/sdk` hosts OC++ directly inside your application. Unlike the
[network client](/build/client), it assembles the OC++ server and routes API
calls through its HTTP router in memory. It opens no HTTP listener and adds no
network hop between the client and server.

<Callout type="warning">
  The V2 SDK is beta. Install the current preview with `bun add @ocpp/sdk@dev`; its API may change before a stable
  release.
</Callout>

## Create a host

`OC++.create()` returns an explicitly owned host. Use `await using` to
release its router, Location services, fibers, and scoped plugin registrations:

```ts
import { OC++ } from "@ocpp/sdk"

await using ocpp = await OC++.create()
const session = await ocpp.sessions.create({
  location: { directory: "/workspace" },
})

await ocpp.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

Call `await ocpp.close()` explicitly when explicit resource management is
not available.

The embedded host uses the same Promise values, declared errors, request
options, and `AsyncIterable` streams as `@ocpp/client`. It exposes the
full generated client and adds the convenience aliases `sessions` and `events`
for the session and event groups.

## Stream events

```ts
for await (const event of ocpp.events.subscribe()) {
  console.log(event.type)
}
```

Pass an `AbortSignal` through the generated request options, or leave an
iteration to cancel its response body.

## Customize

Customize your OC++ instance by registering plugins. Pass plugins to
`OC++.create()` to customize agents, models, tools, and other behavior when
the embedded host starts:

```ts
import { Plugin } from "@ocpp/plugin"
import { OC++ } from "@ocpp/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using ocpp = await OC++.create({ plugins: [plugin] })
```

Call `await ocpp.plugin(plugin)` to register another plugin after startup.

See the [full plugins documentation](/build/plugins) for plugin hooks,
transforms, tools, and the complete plugin context.
