Run the CLI to open OC++ in your browser:

```bash
ocpp
```

It starts the background server if it isn't already running, prints the server URL, and opens the web app. Open or add
projects from the web app's home page.

## Automation

Use `ocpp run` to submit a prompt without opening the web app. It is designed for scripts, CI jobs, and other workflows
that need model output directly in the terminal.

```bash
ocpp run "Explain this repository"
```

Run `ocpp --help` to see every command, including `serve`, `acp`, `auth`, `mcp`, `plugin`, and `service`.

## Background service

By default, OC++ discovers or starts one shared background server for your user account. The web app and every local
OC++ command connect to that server, which owns sessions, configuration, integrations, permissions, and tool execution.

Use `--standalone` to run with a private server, or `--server` to connect to a specific server URL:

```bash
ocpp --standalone
ocpp --server http://localhost:4096
```

With `--standalone`, the private server runs inside the `ocpp` process, so keep it running while you use the web app.

See [Troubleshooting](/troubleshooting) for shared service diagnostics and the [API reference](/api) for server endpoints.
