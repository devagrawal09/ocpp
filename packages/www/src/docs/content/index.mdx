These docs are for the beta version of OC++, which will become OC++ 2.0. The beta is still changing: things may
break, and APIs, configuration, and plugin APIs may change.

OC++ 2 installs and runs as `ocpp`. It does not replace OC++ 1's `ocpp` binary, so you can keep both
versions installed and run them side by side.

## Install

<div data-install-code>
  <CodeBlock
    code={`$ npm install -g @ocpp/cli@beta
$ bun install -g --trust @ocpp/cli@beta
$ pnpm add -g --allow-build=@ocpp/cli @ocpp/cli@beta
$ yarn global add @ocpp/cli@beta
$ curl -fsSL https://ocpp.ai/v2/install | bash`}
  />
</div>

The package uses a trusted postinstall script to select the native `ocpp` binary for your platform. The Bun and pnpm
commands above explicitly allow that script to run.

Homebrew, Arch Linux, Windows package managers, Docker, and standalone binaries are not supported during the beta.

## Connect

OC++ has built in support for many LLM providers. Run `ocpp` to open the web app, then connect a provider with
**Connect provider** in the command palette, or run `ocpp auth login` from the terminal.

See [Providers](/providers) to configure custom providers.

If you'd like easy access to all the best coding models you can try out
[OC++ Console](https://console.ocpp.ai).

You can also try [OpenCode Go](https://ocpp.ai/go) a $10/month subscription
plan that grants you access to the best open source models.

## Customize

Make OC++ your own by editing the [OC++ config](/config), [loading plugins](/plugins), [connecting MCP
servers](/mcp-servers), or [creating commands](/commands). Choose themes and keyboard shortcuts in the web app's
settings.
